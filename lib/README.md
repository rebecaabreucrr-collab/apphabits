# Bibliotecas incluídas (gratuitas, rodam no próprio aparelho)

- **Tesseract.js 5.1.1** (Apache-2.0) — reconhece texto em fotos (cupom, nota, boleto). Idioma: português (`por`, modelo LSTM best_int).
- **PDF.js 4.10.38** (Apache-2.0) — lê o texto de arquivos PDF.

Elas só são baixadas quando você usa "Ler foto ou arquivo" nas Finanças. Nada é enviado para servidores.
