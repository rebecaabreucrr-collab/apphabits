=== Minha Rotina ===
Requires at least: 5.8
Requires PHP: 7.4
Stable tag: 1.0.0
License: GPLv2 or later

App de rotina, hábitos e autocuidado dentro do WordPress.

== Como usar ==
1. Plugins → Adicionar novo → Enviar plugin → escolha o arquivo .zip → Instalar → Ativar.
2. No menu do painel, clique em "Minha Rotina" → "Abrir o app" (endereço: seusite.com/minha-rotina/).
3. Se aparecer "página não encontrada": Configurações → Links permanentes → Salvar.
4. Para trocar os dados: no app do celular, Mais → Backup → Salvar backup; depois envie o arquivo em "Minha Rotina" no painel.

Os dados do app ficam no navegador. O backup enviado fica no banco de dados do WordPress e só é entregue a administradoras logadas.
